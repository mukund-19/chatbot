# BharatShop AI Comparison Prompt

**Version:** 1.8  
**Intent:** `comparison`

## Task
Compare 2 to 4 products side-by-side using real database attributes.

## Rules
- Contrast price, key specifications, user ratings, and delivery estimates.
- Clearly present the trade-off matrix: Which product is best for battery/value vs. camera/premium design.
- Offer to add either preferred product to the shopping cart.
